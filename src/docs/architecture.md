# Clean Minimalistic Ecommerce Platform

## Entidades

### Product

Representa un producto que puede comprarse.

### Category

Agrupa productos.

Ejemplos:

- Mujer
- Hombre
- Rebajas

### Section

Representa un bloque dentro de una página.

Una sección puede ser:

- Image Grid
- Product List
- Featured Product

### Page

Una página está formada por una lista de secciones.

Ejemplos:

- Home
- Mujer
- Hombre

### User

Usuario registrado.

### Cart

Productos seleccionados.

### Order

Compra realizada por un usuario.
